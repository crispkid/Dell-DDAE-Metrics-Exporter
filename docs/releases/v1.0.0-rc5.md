## Delivery and verification boundaries

Retain the RC4 distribution layout: source archive, Linux/macOS amd64/arm64
archives containing the committed source and `bin/ddae-exporter`, source SBOM,
release metadata and SHA-256 checksums. Build with the pinned Go 1.26.6 toolchain.
Only publish generated deliverables from the clean tagged commit; exclude local
credentials, certificates, databases, diagnostic captures and ignored work files.

Rerun available gates, compare repeated platform builds and perform a local
synthetic HTTPS startup check for the macOS arm64 executable. Cross-compilation
is not native runtime/deployment evidence for other platforms. Prior Kafka tests
used a real broker and synthetic DDAE inputs, not this final RC5 artifact or a
complete real DDAE integration. Publish actual results in the release notes and
`release-metadata.json`; this document is authorization, not a claim of success.

Inherited full Harness integration/E2E, security-policy, independent-review and
SDD acceptance limitations remain open until separately satisfied. The known
security script expects two guarded TLS targets while the query client adds a
third; the exception does not change that script. Supply-chain checks must report
their actual result against the clean committed source. A passing component check
does not certify the entire release.

## Operator precautions and recovery

This is a test-only candidate, not a production-ready release. Before testing an
upgrade, stop the exporter and back up the complete state directory. Keep source
identity and configuration consistent, validate readiness and metrics, and use
isolated non-production dependencies. Query-state validation may reject corrupted
files previously accepted by RC4; preserve them for investigation rather than
deleting or automatically repairing them. Binary rollback is not data repair.

The intended publication is
[GitHub v1.0.0-rc5](https://github.com/crispkid/Dell-DDAE-Metrics-Exporter/releases/tag/v1.0.0-rc5).
Its live state and asset checksums are the publication evidence.
