# Portable Harness Changelog

All notable cross-project changes to the shared agent and Harness baseline are
recorded here. Project-only command or requirement changes belong in the
project's own specification history.

## 1.0.0 - 2026-08-14

- Established the portable root `AGENTS.md`, project-context starter, execution
  plan contract, code-review starter, and one stable Harness command interface.
- Made committed `HARNESS/config.env` the isolated executable source of truth
  for stages, commands, network declarations, governance, and evidence policy.
- Added fail-closed strict SDD with canonical active-change selection, stable
  requirement/acceptance/task/test IDs, digest-bound named approvals, executable
  implementation/test paths, traceability, and same-run stage evidence.
- Added explicit amendment rules for Change IDs, specification versioning,
  stable requirement history, append-only specification changelogs, approval
  renewal, regression preservation, trace reset, isolated exploration, and
  structured material-uncertainty decisions.
- Added deterministic project stages, repository and instruction doctors,
  configuration isolation, network declarations, timeouts, redaction, source
  identity, and repository-contained evidence storage.
- Added agent regression and capability evaluation contracts with immutable
  input identities, separate verification, structured failure, trials, graders,
  metrics, artifact manifests, and integrity validation delegated to the
  project-owned validator.
- Published schema version 1 for Harness reports, agent-evaluation cases,
  agent-evaluation results, and latest pointers, with complete JSON examples and
  positive and negative conformance tests.
- Added a complete starter inventory and adoption round-trip selftest for every
  `.example` file, Bash 3.2 portability, failure paths, concurrent evidence, SDD
  closure, and schema validation.
